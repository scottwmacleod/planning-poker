# Security

Please don't report security problems in a public issue, discussion or pull request.

Report them privately through [GitHub's private vulnerability reporting](https://github.com/scottwmacleod/planning-poker/security/advisories/new). Only the maintainer can see the report. Include what you found, how to reproduce it, and what someone could do with it.

You should get a reply within a week. Once a fix is out, the advisory is published with credit to you unless you'd rather stay anonymous.

Only the current `main` branch and the live site at https://planning-poker.scottmacleod.co are supported.
