# Bun as package manager and runtime

planning-poker installs with Bun 1.4.4 and runs its scripts and tools on Bun's runtime: Vite, Vitest and Wrangler. `bun.lock` replaces `package-lock.json`, and `packageManager` in `package.json` is the one place the version lives. Scott decided this on 20 Nov 2026 for the sm_ apps (scottwmacleod/sm-core#35), after a trial on the same commit (planning-poker#120, five CI runs per tool, Bun 1.4.4 against npm 10 and Node 26):

| Median                      | npm + Node | Bun    |
| --------------------------- | ---------- | ------ |
| Install, empty cache        | 5.93 s     | 1.65 s |
| Install, warm cache         | 4.31 s     | 0.13 s |
| Vitest (275 tests)          | 7.91 s     | 8.03 s |
| Vite build                  | 0.82 s     | 0.79 s |
| `wrangler deploy --dry-run` | 1.34 s     | 1.40 s |
| Dev server ready            | 0.43 s     | 0.22 s |

Install is where the time goes; the tools run at the same speed on either runtime.

- **Vitest stays**, run on Bun's runtime with `bun run test`. Under `bun test`, 90 of the 153 tests it ran failed (jsdom).
- **Biome stays** for lint and format. Bun has no linter.
- **Node stays installed** only for `vendor/sm-core/verify.mjs`, which sm-core keeps dependency-free. No script calls `npm`, `npx` or `node` otherwise.
- **Vercel** bundles Bun 1.3.14, which can't read a Bun 1.4 `bun.lock`, so `installCommand` installs 1.4.4 with the official installer first. Drop it once Vercel ships Bun 1.4.
- **CI** passes `package-manager: bun` to sm-core's shared workflows. The room server jobs set up Bun from `packageManager` and run Wrangler on it. Audit runs `bun audit`, and Dependabot uses its `bun` ecosystem.

## Considered options

- **Keep npm.** Nothing broke on npm, but every install was 4 s slower and the suite wants one toolchain across its apps.
- **Bun as package manager only, Node as runtime.** Gets the install speed, but leaves two tools to pin. The trial found nothing that needed Node.
- **Replace Vitest with `bun test`.** Too much rework for no measured gain.
